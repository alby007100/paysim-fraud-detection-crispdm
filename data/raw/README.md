# Raw Data

The original dataset used in this project is:

`Fraud_Detection_Dataset.csv`

The dataset is based on the PaySim financial transaction simulation dataset.

## Dataset Size

- Observations: 6,362,620
- Variables: 11
- File size: approximately 470 MB
- Target variable: `isFraud`

## Expected Location

To run the project, place the dataset at:

`data/raw/Fraud_Detection_Dataset.csv`

The full CSV is not stored directly in this GitHub repository because its size exceeds GitHub's standard single-file upload limit.
