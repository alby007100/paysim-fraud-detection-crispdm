# Outputs

This folder contains the outputs generated by the PaySim fraud detection project.

## Evaluation Metrics

Model performance is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

## Visualizations

This folder may contain figures generated during model evaluation, including:

- Confusion matrices
- ROC curves
- Feature importance plots
- Model comparison charts

## Model Outputs

Saved model artifacts and evaluation results produced during the CRISP-DM modeling and evaluation phases are stored here.
